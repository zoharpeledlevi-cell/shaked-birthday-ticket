# 💖 הזמנה ליום כיף של שקד

אתר הזמנה קטן וחמוד: שקד פותחת קישור בטלפון, עונה "כן" (אין לה ברירה 😈), בוחרת פעילות, אוכל, תאריך ושעה, ומקבלת כרטיס כניסה שאפשר לשמור בגלריה.

## מה יש בתיקייה

| קובץ | מה הוא עושה |
|------|-------------|
| `content.js` | **כל הטקסטים, האפשרויות והאימוג'ים.** זה הקובץ היחיד שצריך לשנות |
| `index.html` | המבנה של הדף |
| `style.css` | העיצוב והאנימציות |
| `script.js` | ההתנהגות (המעטפה, הכפתור הבורח, הכרטיסים, לוח השנה, השמירה, הוואטסאפ) |
| `preview.png` | התמונה שמופיעה בוואטסאפ כששולחים את הקישור |
| `README.md` | הקובץ הזה |

## 🚀 איך מעלים את האתר לאינטרנט (GitHub Pages), צעד אחר צעד

זה בחינם, ולוקח בערך 10 דקות.

### שלב 1: פותחים חשבון ב-GitHub
1. נכנסים ל-[github.com](https://github.com) ולוחצים על **Sign up**.
2. ממלאים אימייל, סיסמה ושם משתמש. **שם המשתמש יופיע בקישור**, אז כדאי לבחור משהו נחמד.
3. מאשרים את המייל שמגיע.

### שלב 2: יוצרים "מאגר" (Repository), כלומר תיקייה בענן
1. אחרי ההתחברות, לוחצים על ה-**+** בפינה הימנית העליונה ← **New repository**.
2. ב-**Repository name** כותבים שם באנגלית, בלי רווחים. למשל: `shaked-birthday`
3. מסמנים **Public** (חייב להיות ציבורי כדי שהאתר יעבוד בחינם).
4. לוחצים למטה על **Create repository**.

### שלב 3: מעלים את הקבצים (בגרירה)
1. בעמוד שנפתח מחפשים את הקישור **uploading an existing file** ולוחצים עליו.
2. פותחים במחשב את התיקייה `shaked-birthday`, מסמנים את **6 הקבצים** (`index.html`, `style.css`, `script.js`, `content.js`, `preview.png`, `README.md`) וגוררים אותם לחלון של GitHub.
   - ⚠️ גוררים את **הקבצים עצמם**, לא את התיקייה.
3. מחכים שכל הקבצים יופיעו ברשימה.
4. גוללים למטה ולוחצים על הכפתור הירוק **Commit changes**.

### שלב 4: מפעילים את האתר (GitHub Pages)
1. בעמוד של המאגר לוחצים למעלה על **Settings** (סמל גלגל שיניים ⚙️).
2. בתפריט שבצד לוחצים על **Pages**.
3. תחת **Build and deployment**:
   - ב-**Source** בוחרים **Deploy from a branch**
   - ב-**Branch** בוחרים **main**, ולידו **/(root)**
   - לוחצים **Save**
4. מחכים 1–2 דקות ומרעננים את העמוד.

### שלב 5: איפה הקישור לשלוח לשקד? 🔗
- באותו עמוד (**Settings ← Pages**) יופיע למעלה: **"Your site is live at..."** ולידו כפתור **Visit site**.
- הקישור נראה ככה:
  `https://שם-המשתמש-שלך.github.io/shaked-birthday/`
- **לפני ששולחים, עושים קודם את שלבים 6 ו-7** 👇

### שלב 6: תמונה וכותרת לקישור בוואטסאפ 🖼️
כדי שבוואטסאפ הקישור יופיע עם תמונה של מעטפה והכותרת "💌 שקודי, יש לך הזמנה סודית!":
1. במאגר ב-GitHub לוחצים על הקובץ **`index.html`** ואז על **העיפרון ✏️**.
2. מחפשים למעלה את השורה עם `USERNAME` (שורה 14):
   ```html
   <meta property="og:image" content="https://USERNAME.github.io/shaked-birthday/preview.png">
   ```
3. מחליפים **רק** את המילה `USERNAME` בשם המשתמש שלך ב-GitHub (בדיוק כמו שהוא מופיע בקישור של האתר).
   - אם קראת למאגר בשם אחר מ-`shaked-birthday`, מחליפים גם אותו.
4. לוחצים **Commit changes**.
5. אפשר גם לשנות שם את הכותרת (`og:title`) ואת המשפט שמתחתיה (`og:description`).

> 💡 וואטסאפ זוכר תצוגה מקדימה של קישור שכבר נשלח. לכן כדאי לבדוק קודם בשליחה לעצמך, ורק אחרי שזה נראה טוב לשלוח לשקודי.

### שלב 7: הוואטסאפ שלך בכפתור "שלחי לאחותך" 💬
במסך האחרון יש לשקודי כפתור ירוק ששולח לך הודעה עם כל מה שבחרה.
1. ב-`content.js`, בחלק `whatsapp`, כותבים את המספר שלך ב-`phone`:
   ```js
   phone: "972501234567",   ← 050-1234567 נכתב כך: 972 + המספר בלי ה-0 שבהתחלה
   ```
2. אם משאירים ריק (`""`), וואטסאפ ייתן לשקודי לבחור למי לשלוח.
3. את נוסח ההודעה אפשר לשנות ב-`message` באותו מקום.

### שלב 8: שולחים! 💌
- **פותחים את הקישור בטלפון ועוברים על כל המסלול** 😉
- מעתיקים את הקישור ושולחים לשקודי בוואטסאפ.

## ✏️ איך משנים טקסט (ישירות באתר של GitHub, בלי להוריד כלום)

1. נכנסים למאגר ב-GitHub ולוחצים על הקובץ **`content.js`**.
2. לוחצים על סמל **העיפרון ✏️** (Edit this file) בפינה הימנית העליונה של הקובץ.
3. משנים את מה שרוצים. כל חלק מסומן בהערה בעברית (שורות שמתחילות ב-`//`).
4. לוחצים על הכפתור הירוק **Commit changes...**, ושוב **Commit changes** בחלון שנפתח.
5. מחכים דקה-שתיים ומרעננים את האתר. השינוי יופיע.

### ⚠️ חוקי זהב כשעורכים
- משנים **רק את מה שבין המירכאות** `"כמו כאן"`.
- **לא מוחקים** מירכאות `"`, פסיקים `,` או סוגריים `{ } [ ]`.
- אם האתר פתאום לבן וריק, כנראה נמחק פסיק או מירכאה. אפשר לבטל: בעמוד של הקובץ לוחצים **History**, ומשם חוזרים לגרסה הקודמת (או פשוט מתקנים את הסימן שחסר).

### דוגמאות
**לשנות משפט:**
```js
title: "שקודי!!!",        ←  משנים ל:  title: "שקודי מתוקה!!!",
```

**להוסיף אפשרות פעילות** (ב-`activity`, בתוך `options`): מעתיקים שורה קיימת, מדביקים מתחת ומשנים:
```js
{ emoji: "🎳", name: "באולינג" },
{ emoji: "🎬", name: "סרט בקולנוע" },   ← שורה חדשה
```
אפשר גם להשאיר 2 כרטיסים בלבד, או כל מספר אחר. הרשת מסתדרת לבד.

**להוסיף טקסט לכפתור ה"לא":** מוסיפים שורה לרשימה `noButtons`. הכפתור נעלם אחרי הטקסט האחרון.

**לשנות את חוק חסימת הבוקר** (ב-`blockRules`):
```js
from: "2026-10-04",      ← מאיזה תאריך הבוקר חסום
to: "2026-10-31",        ← עד איזה תאריך
exceptWeekdays: [6],     ← ימים שבהם לא חוסמים (6 = שבת. להוסיף שישי: [5, 6])
message: "בבוקר יש בית ספר 🤓📚",
```
